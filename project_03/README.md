# Project 03 - Polynomial Regression

## Overview

This project implements Polynomial Regression to predict CO2 emissions based on vehicle engine size.

Unlike Simple Linear Regression, Polynomial Regression can model nonlinear relationships between input and target variables.

## Dataset

Fuel Consumption Dataset

## Features

- Engine Size (ENGINESIZE)

## Target

- CO2 Emissions (CO2EMISSIONS)

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Concepts

- Data Loading
- Data Preprocessing
- Train-Test Split
- Polynomial Features
- Polynomial Regression
- Degree Selection
- Model Prediction
- Model Evaluation
- Mean Absolute Error (MAE)
- R2 Score

## Model

Polynomial Regression (Degree = 2)

Equation:

CO2EMISSIONS = b + w1 × ENGINESIZE + w2 × ENGINESIZE²

## Visualization

- Scatter Plot of Engine Size and CO2 Emissions
- Polynomial Regression Curve

## Evaluation

- Mean Absolute Error (MAE)
- R2 Score

## Purpose

Understanding nonlinear relationships and learning how polynomial features improve the flexibility of regression models.
