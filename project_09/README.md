# Project 09 - Hierarchical Clustering

## Overview

This project implements the Hierarchical Clustering algorithm to group data points into different clusters based on their similarities and distances.

## Dataset

Synthetic Dataset generated using `make_blobs`

- 2,000 Samples
- 2 Features
- 4 Centers

## Technologies

- Python
- NumPy
- Matplotlib
- SciPy
- Scikit-learn

## Concepts

- Data Generation
- Data Standardization
- Hierarchical Clustering
- Agglomerative Clustering
- Dendrogram
- Data Visualization

## Model

Agglomerative Clustering

- Number of Clusters: 4
- Linkage: Ward

## Visualization

- Dataset Scatter Plot
- Dendrogram
- Clustering Results

## Purpose

Understanding hierarchical clustering and learning how to group data points based on their similarities and distances.
