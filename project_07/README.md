# Project 07 - Support Vector Machine (SVM)

## Overview

This project implements the Support Vector Machine (SVM) algorithm to classify cell samples based on their characteristics.

The model uses cell-related features to predict whether a sample is benign or malignant.

## Dataset

Cell Samples Dataset (`cell_samples.csv`)

## Features

- Clump
- UnifSize
- UnifShape
- MargAdh
- SingEpiSize
- BareNuc
- BlandChrom
- NormNucl
- Mit
