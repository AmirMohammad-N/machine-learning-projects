# Project 04 - KNN Classification

## Overview

This project implements the K-Nearest Neighbors (KNN) algorithm to classify telecommunications customers into different service categories.

The model uses customer information to predict their service category.

## Dataset

Telecommunications Customer Dataset (`teleCust1000t.csv`)

## Features

- Region
- Tenure
- Age
- Marital Status
- Address
- Income
- Education
- Employment
- Retirement Status
- Gender
- Residence

## Target

- Customer Category (custcat)

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Concepts

- Data Loading
- Train-Test Split
- Feature Standardization
- KNN Classification
- Finding the Best K
- Model Prediction
- Accuracy Score
- Model Evaluation

## Model

K-Nearest Neighbors (KNN)

## Visualization

- Accuracy vs K Values

## Evaluation

- Best K
- Best Accuracy
- Training Accuracy
- Testing Accuracy

## Purpose

Understanding distance-based classification algorithms and learning how to select the optimal number of neighbors.
