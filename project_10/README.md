# Project 10 - DBSCAN Clustering

## Overview

This project implements the DBSCAN algorithm to group data points based on their density and identify noise points.

## Dataset

Synthetic Dataset generated using `make_moons`

- 1,000 Samples
- 2 Features
- Noise: 0.08

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Concepts

- Data Generation
- Data Standardization
- DBSCAN Clustering
- Density-Based Clustering
- Noise Detection
- Data Visualization

## Model

DBSCAN

- Epsilon (eps): 0.3
- Minimum Samples: 5

## Visualization

- Original Dataset
- Clustering Results
- Noise Points

## Purpose

Understanding density-based clustering and learning how to identify clusters and detect noise points.
