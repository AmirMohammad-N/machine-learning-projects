# Project 08 - K-Means Clustering

## Overview

This project implements the K-Means Clustering algorithm to group randomly generated data points into different clusters.

The model uses two-dimensional data to identify groups based on the similarity and distance between points.

## Dataset

Synthetic Dataset generated using `make_blobs`

- 2,000 Samples
- 2 Features (X, Y)
- 3 Centers

## Features

- X
- Y

## Target

- No target variable (Unsupervised Learning)

## Technologies

- Python
- NumPy
- Matplotlib
- Scikit-learn

## Concepts

- Data Generation
- Feature Standardization
- K-Means Clustering
- Cluster Assignment
- Centroid Calculation
- Data Visualization
- Inertia
- Elbow Method
- Finding the Optimal K

## Model

K-Means Clustering

- Number of Clusters: 3
- Random State: 42
- Number of Initializations: 10

## Visualization

- K-Means Clustering Plot
- Cluster Centroids
- Elbow Method Plot

## Evaluation

- Inertia
- Elbow Method
- Optimal Number of Clusters

## Purpose

Understanding unsupervised learning algorithms and learning how to group data points into clusters based on their similarity.
