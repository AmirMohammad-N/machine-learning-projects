# Project 01 - Simple Linear Regression

## Overview

This project implements Simple Linear Regression to predict CO2 emissions based on vehicle engine size.

The model learns the relationship between engine size and CO2 emissions using a linear equation.

## Dataset

Fuel Consumption Dataset

## Features

- Engine Size (ENGINESIZE)

## Target

- CO2 Emissions (CO2EMISSIONS)

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Concepts

- Data Loading
- Data Preprocessing
- Train-Test Split
- Simple Linear Regression
- Model Coefficients
- Intercept
- Data Visualization

## Model

Simple Linear Regression

Equation:

CO2EMISSIONS = w × ENGINESIZE + b

## Visualization

- Training Data with Regression Line
- Testing Data with Regression Line

## Purpose

Understanding the relationship between a single input feature and a continuous target variable using Linear Regression.
