# Project 05 - Decision Tree Classification

## Overview

This project implements the Decision Tree algorithm to classify drugs based on patient information.

The model uses medical features to predict the appropriate drug category.

## Dataset

Drug Classification Dataset (`drug200.csv`)

## Features

- Age
- Sex
- Blood Pressure (BP)
- Cholesterol
- Na_to_K

## Target

- Drug

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn

## Concepts

- Data Loading
- Data Preprocessing
- Label Encoding
- Train-Test Split
- Decision Tree Classification
- Entropy
- Model Prediction
- Accuracy Score
- Model Evaluation

## Model

Decision Tree Classifier

- Criterion: Entropy
- Max Depth: 4

## Evaluation

- Accuracy Score

## Purpose

Understanding tree-based classification algorithms and learning how to classify data using decision rules.
