# Project 02 - Multiple Linear Regression

## Overview

This project implements Multiple Linear Regression to predict CO2 emissions using multiple vehicle features.

The model uses engine size, number of cylinders, and combined fuel consumption to estimate CO2 emissions.

## Dataset

Fuel Consumption Dataset

## Features

- Engine Size (ENGINESIZE)
- Cylinders (CYLINDERS)
- Combined Fuel Consumption (FUELCONSUMPTION_COMB)

## Target

- CO2 Emissions (CO2EMISSIONS)

## Technologies

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Concepts

- Data Loading
- Data Preprocessing
- Train-Test Split
- Multiple Linear Regression
- Model Coefficients
- Intercept
- Model Prediction
- Model Evaluation
- Mean Absolute Error (MAE)
- R2 Score

## Model

Multiple Linear Regression

Equation:

CO2EMISSIONS = w1 × ENGINESIZE + w2 × CYLINDERS + w3 × FUELCONSUMPTION_COMB + b

## Visualization

- Actual vs Predicted (Training Data)
- Actual vs Predicted (Testing Data)

## Evaluation

- Mean Absolute Error (MAE)
- R2 Score

## Purpose

Understanding how multiple input features can be used to predict a continuous target variable.
