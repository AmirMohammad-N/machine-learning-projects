# Project 06 - Logistic Regression

## Overview

This project implements the Logistic Regression algorithm to predict customer churn.

The model uses customer information and service-related features to predict whether a customer will leave the service.

## Dataset

Customer Churn Dataset (`ChurnData.csv`)

## Features

- Tenure
- Age
- Address
- Income
- Education
- Employment
- Equipment

## Target

- Churn

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn

## Concepts

- Data Loading
- Train-Test Split
- Feature Standardization
- Logistic Regression
- Model Prediction
- Jaccard Score
- Model Evaluation

## Model

Logistic Regression

- Solver: liblinear
- C: 0.01

## Evaluation

- Jaccard Score

## Purpose

Understanding probability-based classification algorithms and learning how to predict binary outcomes using Logistic Regression.
